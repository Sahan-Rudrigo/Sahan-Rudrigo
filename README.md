## 👋 About Me

I'm a **Computer Engineering graduate** (B.Sc. Hons., Second Class Upper) from the **University of Sri Jayewardenepura, Sri Lanka**, specializing in **Artificial Intelligence, Machine Learning, Computer Vision and Large Language Models**.

- 🔁 I work across the **full AI lifecycle**: data processing, model development, cloud deployment and application integration.
- 🏥🛒📡💼 I've built AI solutions for **healthcare, e-commerce, telecommunications and recruitment**.
- 🌏 Former **AI/ML Engineer Intern** at Lead Innovationz (Melbourne, remote).
- 📍 Based in Sri Lanka, open to **remote and relocation opportunities**.
- 🎯 **Looking for AI Engineer / Machine Learning Engineer roles.**

##  What I Work On

| Area | Focus |
|---|---|
|  **LLMs** | Fine-tuning (LoRA, QLoRA, PEFT), prompt engineering, Hugging Face Transformers |
|  **RAG** | Retrieval pipelines, embeddings, vector search with Pinecone |
|  **Agentic AI** | Multi-agent systems, tool-using agents, orchestration with LangGraph and LangChain |
|  **Computer Vision** | Detection, tracking, OCR, re-identification, vision-language models |
|  **Recommender Systems** | Collaborative filtering, content-based and hybrid approaches |
|  **MLOps** | Automated retraining, Docker, microservices, cloud deployment on AWS |

### 🕸️ Agentic AI

I design LLM systems that **reason, call tools and coordinate**, not just answer prompts:

- Agent orchestration and stateful workflows with **LangGraph** and **LangChain**
- **Multi-agent systems** with planning, tool calling and task delegation
- **RAG-grounded agents** using vector stores and embeddings
- Serving agents as **FastAPI** services, containerized with Docker

> 🔭 **Currently exploring:** Model Context Protocol (MCP), agent evaluation, and observability for LLM agents.
